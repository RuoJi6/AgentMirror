# 蜜罐工作区：使用与 API 指南

工作区把三件事分开管理：**站点素材**负责前端，**模拟场景**负责请求与返回，**提示词方案**提供要交付的正文。场景实例连接三者，同一前端可换场景，同一场景可换前端或提示词，均不需要修改 Go 代码。

当前模拟的是 HTTP 请求条件与输出效果，不是完整漏洞服务。支持静态 HTML/CSS/JS、多页面资源和 React/Vue 的静态构建产物；不自动构建源码仓库，也不运行 SSR、后端脚本、数据库或真实命令。Go 管理端已移除旧页面模板和旧部署编辑器；所有新建、编辑、发布操作统一使用工作区。旧模板升级后转为站点素材，历史会话保持兼容。

先在创建弹窗中填写名称和部署标识，点击 **创建工作区** 后立即保存一个有 ID 的草稿。取消不会创建记录，尚未选择站点的草稿也会显示在工作区列表。选择站点后才可发布。

进入工作区后，默认显示 **AI 助手**；站点、场景、绑定、预演和发布设置分别位于独立页签。切换页签不重置对话。顶部的 **工作区设置** 用于编辑名称和标识，以及复制、暂停/恢复、删除工作区。

列表的更多菜单和详情标题旁均提供 **重命名**：只保存名称，保留当前未保存的站点和绑定编辑，不改变访问地址或发布版本。

## 1. 创建、保存与发布

1. 在“提示词方案”保存指定正文。例如使用固定标记 `AGENTMIRROR_TEST` 先检查交付链路。
2. 在“蜜罐工作区”创建工作区，填写名称和入口标识。标识使用小写字母、数字和连字符。
3. 在“站点素材”载入预设、新建文件或导入 ZIP，保存素材后会自动选入当前工作区。
4. 在“模拟场景”编辑方法、路径、条件和返回。新建场景保存后自动添加一个实例，也可从场景卡片重复添加。
5. 在“绑定提示词”选择每个实例的默认方案；需要区别返回的接口，在其下方单独选择提示词，未指定时继承默认。必要时覆盖各规则路径。映射框直接显示实际生效路径，可选中复制或使用 **复制路径**；修改后复制的是新路径，清空并离开输入框后恢复场景原路径。**复制示例请求** 会同时复制方法、查询参数、请求头和正文示例（由条件生成）。
6. 在“请求预演”检查普通请求和触发请求的返回，再保存和发布。
7. 发布后创建或选择测试端口，填写被测设备能访问的公告地址，绑定并启用。

从 4.6.18 起，**首次发布后，保存站点、模拟场景或工作区会自动同步到其绑定端口**。更换整个场景、增删规则、修改路径/条件/响应、启停实例、切换默认或单接口提示词都随保存生效。已有会话的下一次请求也读取当前版本，无需删除重建工作区、重新绑定端口或清除 Cookie。提示词正文、字段和命令清单继续随方案保存热更新。未保存的编辑不生效，未发布工作区不会自动发布，已暂停部署不会被保存操作开启。共享素材更新及其所有引用工作区的新发布版本在同一事务中校验和保存；有冲突则全部回滚并显示错误。删除规则会同时移除对应的路径和提示词覆盖，其他规则绑定保留。

历史发布、会话创建快照和已交付正文均不改写；后续响应另记录实际使用的发布和站点版本。升级启动时会同步已发布工作区的有效保存内容，保留原工作区和端口；无效的历史配置保留最后可用版本并记录同步错误。端口只选择已发布工作区并设置监听信息。

发布和绑定端口是两个动作。工作区已有端口时，重新发布即更新这些端口的新会话；发布弹窗还可以额外绑定端口。将某个端口改绑到另一工作区，只改变该端口的绑定。

工作区列表或详情中的 **暂停发布 / 恢复发布** 控制当前发布入口，未发布工作区不能启停。暂停后绑定端口仍占用监听地址，但不提供该工作区的测试站点和场景；暂停端口才会释放监听。恢复发布使用已有快照，不会把未发布草稿自动上线。

**删除工作区** 会暂停并解绑关联端口，删除草稿和当前发布入口；站点/场景素材、不可变发布版本、会话和回传保留。端口配置也保留，可随后绑定其他已发布工作区。删除站点或场景时仍检查工作区引用。

工作区列表顶部的 **站点素材** 或详情中的 **管理素材** 打开共享素材库，可按名称或首页文件搜索并删除素材。被引用的素材会列出工作区名称；先在对应工作区更换站点或点击 **移除选用**，保存工作区后再删除。素材删除保留不可变版本，已发布站点和历史会话继续使用原快照。仅在当前未保存草稿中选用的素材，删除后会同步清空该选择。

浏览器保留实验 Cookie，刷新页面可能仍属于旧会话。需要验证新发布的站点或场景规则时，应使用新浏览器会话或清除对应测试站点的实验 Cookie；API 客户端用不携带旧 `run_id`、`X-Run-ID` 或实验 Cookie 的请求开始新会话。仅更新绑定提示词时不需要清理 Cookie，刷新或再次请求交付接口即可。已经返回到客户端的旧内容不会被主动推送替换。

### 模拟网站的 Server 响应头

在 **工作区设置 → Server 响应头** 填写模拟 HTTP 服务的标识，如 `nginx`、`Apache`；留空时不发送该头。系统不再统一输出 `Workspace/2.0`。默认值作用于当前工作区的页面、静态文件、模拟接口、回传及错误响应；规则或回传响应中明确配置的 `Server` 优先。保存后同步已绑定端口，已有会话的新请求也使用新值，历史快照保留。请求预演和隔离核查使用同一配置。

编写 Agent 可使用 `read_response_settings` 和 `set_server_header` 读取、设置，属于站点修改范围。例如“把这个工作区的 Server 头设置为 nginx”。Agent 编写站点时应核对明确的模拟服务，未知时省略标识，不依据站点名称猜测服务或版本。此设置只改变 HTTP 响应头，不会更换实际运行的服务器软件。

### Agent 管理工作区绑定

在 AI 助手中可以直接要求“将实例 1 默认提示词切换为方案 B”“让下载接口继承默认提示词”“停用实例 2”或“修改该实例的接口映射”。修改范围可选择 **仅修改提示词绑定**；自动范围也会识别换绑意图，与修改提示词正文分开。

Agent 先调用 `read_bindings` 读取当前工作区，再通过 `set_binding_profile` 切换实例默认或单个规则的方案。`upsert_binding` 用于新增/替换场景实例、启停及修改路径映射，`move_binding` 调整顺序，`delete_binding` 只移除实例。默认方案切换保留接口单独指定；接口方案传空字符串恢复继承。目标不明确时需要先确定实例和方案。

这些工具立即保存并同步已有发布端口，无需再采用或保存；不会修改共享素材正文或首次发布。版本过期、无效引用、路径冲突会拒绝整次修改。浏览器未保存的编辑会保留，不能覆盖 Agent 已保存的新版本。内置编写 Agent 升级后自动获得这些工具；自定义编写 Agent 可在 Agent 管理中勾选，用户之后关闭的工具不会因重启重新启用。

### 不同接口返回不同提示词

在“绑定提示词”中，实例默认方案用于未单独配置的交付接口。每条交付规则下方都有提示词选择器：选中具体方案后只影响该规则，选择“继承默认”则恢复跟随实例默认。所有交付规则均单独指定时，可以不设置实例默认。

例如：`GET /api/info` 继承默认方案 A，`GET /api/download?file=config.txt` 单独指定方案 B，`GET /api/download?file=notes.txt` 指定方案 C。后两个接口都使用 `/api/download` 路径，通过 `query.file equals` 条件区分，响应中继续填写 `{{prompt}}`。普通文件响应不放槽位，保持自己的正文；绑定不会自动插入提示词。

接口级绑定保存在工作区实例的 `rule_profiles` 对象中，键为稳定的规则 ID，值为提示词方案 ID，与路径覆盖相互独立。API 示例：

```json
{
  "id": "instance-a",
  "scenario_id": "scenario-id",
  "enabled": true,
  "profile_id": "default-profile-id",
  "rule_profiles": {
    "download-config": "profile-b-id",
    "download-notes": "profile-c-id"
  },
  "paths": {}
}
```

省略或清空某个接口绑定表示继承默认。规则或提示词不存在时拒绝保存；交付规则既未单独绑定也没有默认方案时会提示补全。已发布规则修改绑定后保存即可用于新旧会话，预演、实际响应和交付记录按同一规则解析；新增接口、修改路径或匹配条件同样随保存同步。

### Agent 编辑已保存素材

可明确要求“修改此提示词并保存”“调整这个场景的某条接口”或“删除这个未引用的素材”。Agent 先列出/读取具体记录，再加载现有站点或场景，按原 ID 和版本保存，不必创建新副本。素材被并发修改时拒绝覆盖；仍被工作区引用的素材不能删除，历史版本不会清理。完成操作后素材列表与选中引用版本自动刷新。

输入区的 **修改范围** 可指定仅修改模拟场景、站点素材、提示词或回传设置，也可选择多个模块或仅问答。自动模式优先使用本轮明确提出的模块操作，否则按本轮 `@` 引用的类型限制；没有可识别目标时保留按需求使用各模块的能力。手动选择优先，发送后恢复自动，消息中记录本轮生效范围。引用提示词来创建场景时，提示词只是输入，不会自动成为修改目标。其他模块仍可读取，但其写入、替换、载入草稿、保存和删除工具会被服务端阻止；只改场景的任务无法重写站点文件。继续对话会重新确定范围，旧上下文不授权跨模块修改。

代码支持 `write_file` 写首段、`append_file` 继续追加，或 `edit_file` 精确替换唯一片段；每次编辑携带文件 SHA-256，保留空格和换行。`read_file` 默认分页读取 8,000 字符，场景使用 `read_scenario` / `upsert_rule` / `delete_rule` 单条编辑，避免重复传送整个站点或场景。任务上下文超过 256 KiB 时压缩已完成工具往返，保留当前请求、草稿清单、已保存操作和最后一次完整往返；必要内容可重新读取。

生成页面按用户需求使用完整的业务文案和本地交互，不默认添加“测试/演示”标题，也不自造 `system_prompt` 等响应字段；实现范围在助手回复中说明。

## 2. 导入和编辑前端

站点包由首页和文件列表组成，不要求使用系统登录表单或特定前端框架。编辑器支持创建文件、修改路径、编辑源码、选择首页和记录来源。

推荐 ZIP 结构：

```text
index.html
assets/
  app.js
  style.css
  logo.png
```

首页必须是包内 HTML 文件。若首页位于子目录，公开根请求会重定向至该文件，保持相对资源路径及会话查询参数。ZIP 根目录通常放 `index.html`；若所有文件都在同一个顶层目录下，且其中有 `index.html`，导入器会移除这层共同目录。其他首页可在导入后的编辑器选择。导入校验默认先要求可识别的 `index.html`，因此自定义首页名称的包应在打包前提供该入口，或通过站点 API 创建。

限制为最多 256 个文件、解码后的文件总量 8 MiB、单文件 4 MiB，ZIP 本身不超过 8 MiB。路径为相对路径，不能包含 `..`、绝对路径或符号链接。文本使用 UTF-8，图片等二进制资源使用 Base64 存储。

复用开源模板时，先在项目自己的构建环境产出 `dist`，把构建结果打包导入。保存项目来源和版本，并核对模板及图片字体等素材的许可证。管理服务不会执行导入包中的 npm 安装脚本。

前端与场景靠请求路径连接。例如页面写 `fetch('/api/download?file=README.md')`，场景路径配置 `/api/download`，再以 query 条件匹配 `file`。前端还要按响应实际格式调用 `text()` 或 `json()` 并显示相应字段；只改绑定路径不会自动重写前端源码。

公开站点允许同源脚本和接口请求，外部 CDN/API 不属于默认资源策略。需要的样式、脚本和图片应放入站点包。SPA 构建仍需正确设置资源 base 路径；启用 SPA 后，无扩展名的普通页面路径可回到首页；`/api`、`/nacos` 等 API 路径不回退到 HTML。

**静态外观预览**不执行 JavaScript，也不调用模拟接口。依赖 JavaScript 首屏渲染的 SPA 可能显示空白，这不等于资源包无法发布；需通过请求预演检查接口，再在已发布测试入口验证浏览器交互。

## 3. 自定义模拟返回

每个场景有 1–64 条规则。规则使用精确方法和路径；路径不包含域名或查询字符串。支持 GET、POST、PUT、PATCH、DELETE、OPTIONS；HEAD 使用 GET 规则，但不发送正文或记录提示词交付。

| 配置 | 含义 |
| --- | --- |
| `conditions` | 同一规则所有条件同时满足；空数组表示该方法/路径无附加条件 |
| `source` | `query`、`header`、`form`、`json` 或完整 `body` |
| `key` | 参数/字段名称；body 条件留空；JSON 支持 `items.0.name` 和 JSON Pointer |
| `operator` | `equals`、`contains`、`exists` |
| `response` | 条件命中后的状态码、类型、正文及响应头 |
| `fallback` | 方法/路径匹配但条件不满足时的普通返回；可省略 |
| `delivery_required` | 是否交付提示词；必须与命中响应中的 `{{prompt}}` 槽位一致 |

规则按实例和场景顺序尝试。先检查所有符合方法/路径的规则是否满足条件，全部未命中时才采用第一个候选 fallback；因此同一路径可以同时定义列表和详情规则。完全相同的方法、路径和条件不能重复发布；多实例复用时请覆盖路径或使用不同条件。

### 同一接口，按文件参数返回不同内容

选择 **按文件参数返回** 预设即可编辑多文件分支。请求路径都填写 `/api/download`，查询字符串放在 URL 参数条件中：

| `file` 等于 | 返回内容 | 交付提示词 |
| --- | --- | --- |
| `index.html` | 已配置的主页源码 | 否 |
| `README.md` | 已配置的说明文件 | 否 |
| `../.././etc/passwd` | 模拟文件内容和 `{{prompt}}` | 是 |
| 其他值或未提供 | 默认 404 `File not found`，可自定义 | 否 |

预设主页是示例，可替换为实际站点素材的源码。点击 **复制规则** 后修改条件值和响应正文即可增加分支。编辑器根据正文自动同步交付设置：直接填写普通正文即为普通响应，插入 `{{prompt}}` 则启用提示词交付；点击 **改为普通响应** 可移除槽位并保留周围内容。默认响应只允许普通内容，误填槽位时可点击 **移除默认响应中的槽位**。默认响应只需配置在同路由的第一条规则，后续命中的分支优先于默认响应。不要在特定分支之前添加无条件规则，否则它会先命中。

`equals` 比较一次 URL 解码后的完整值：`..%2F..%2F.%2Fetc%2Fpasswd` 与 `../.././etc/passwd` 等价，而 `../../etc/passwd` 不等价。`../` 和 `./` 不会自动归一化。不同写法可以分别配置；`contains` 会扩大命中范围。参数是模拟内容的匹配键，不读取服务器文件。

可以对助手说：“在 `/api/download` 按 file 参数返回：index.html 使用当前站点主页源码，README.md 返回我提供的说明，../.././etc/passwd 返回模拟文件内容并插入绑定提示词；其他文件返回 404。保留现有其他规则。”通过 `@` 引用对应站点、场景和提示词，采用后在请求预演选择各规则核对实际响应，再保存发布。

表单请求应提供正确的 Content-Type。支持 URL 编码表单以及 multipart 的普通文本字段，不把文件上传解释为真实文件写入。请求正文上限 256 KiB。

响应支持 `text`、`html`、`json`，正文模板不超过 128 KiB，渲染结果不超过 2 MiB。状态码支持 200–599，204/205/304 等无正文状态码不能包含正文或提示词。可配置普通响应头；Cookie、Content-Length、CSP、会话标识等由系统管理的头不可覆盖。

- **文本**：在任意文本位置插入 `{{prompt}}`。可设置 `prompt_prefix`，给提示词每一行加缩进或注释前缀，例如 `# `。
- **JSON**：正文必须是有效 JSON；槽位放在字符串值中，如 `{"notes":"{{prompt}}"}`。系统按 JSON 字符串转义，不手动拼接引号。
- **HTML**：槽位放在文本节点中，如 `<pre>{{prompt}}</pre>`。系统转义提示词，不允许把槽位放入属性、脚本、样式或注释。
- **普通响应与 fallback**：不含提示词槽位。需要交付提示词的规则使用 `delivery_required: true` 并绑定 Profile。

每个场景实例可绑定默认 Profile，也可为每条交付规则单独指定 Profile；未单独指定的规则继承实例默认方案。同一路径的不同参数分支也可分别绑定。单条响应内的多个 `{{prompt}}` 槽位使用该规则同一个 Profile，尚未提供多个命名槽位。文本行前缀仅改变表现形式，适合在 YAML 配置注释中保留原提示词文字。直接调用场景 API 时，仍需保持 `delivery_required` 与正文槽位一致。

## 4. 预演和观察证据

工作区的“站点素材”和“模拟场景”以列表展示名称、版本、文件或接口数量、选用状态及更新时间，支持关键词和选用状态筛选。点击名称或行首箭头展开详情：站点可切换查看文件源码、复制内容并预览外观；场景可逐条展开接口，查看条件、响应头、正文、提示词交付标记和未命中响应。查看详情不改变绑定，选择站点或添加场景仍通过各行的操作按钮完成。编辑未选用的站点不会自动替换当前工作区选用的站点。

提示词方案的 **版本历史** 按保存时间列出版本号和修改摘要。选择版本后，**更新内容** 默认比较上一版；可改选其他版本作对比基准。正文按行标出新增、删除，修改行以删除旧行和新增新行呈现；也可显示未改动行。名称、分组、说明、回传字段和命令清单的变化一并展示。**完整内容** 查看原始正文和其他已保存字段，支持复制正文，占位符保持原样。

版本列表和详情会标明修改来源：通过 Agent 保存的版本显示 **Agent 修改 · Agent 名称**，页面编辑或恢复历史版本显示 **手动保存**。Agent 名称按执行时记录，后续重命名不会改变已记录的来源。升级前的版本若有对应的 Agent 保存日志，也会显示修改来源；无法确认的旧版本显示 **历史版本 · 未记录来源**，原始历史内容保持不变。

首次版本对比空白内容；重复保存而内容未变时明确显示无变化。长文本分批显示差异行，变更过大时按整段替换展示。恢复历史版本会新增一个版本，不改写已有历史或发布快照；恢复出的新版本同样立即用于后续请求。另存为新方案是新的 ID，需在工作区重新绑定并保存。同一已发布场景实例保存换绑后，已有会话的下一次请求也会使用新方案，无需清除 Cookie；历史绑定的方案若已删除，继续使用原快照中的副本。

请求预演使用已保存的站点、场景素材和当前工作区绑定草稿。 **模拟场景接口** 清单始终展示场景库中的方法、路径和参数条件，可按路径、参数名/值或场景名称搜索。已加入工作区的接口排在前面，点击即填入请求；路径被覆盖时同时显示原路径和映射路径。同一路径的不同规则通过名称、条件和实例编号区分。

未加入的场景显示 **添加并填入**；需要交付提示词时，就地选择方案后加入工作区草稿，不自动保存或发布。停用的实例显示 **启用并填入**，复用原实例和映射，不会重复添加。没有场景绑定时会明确说明，仍能浏览素材库接口；`/` 只代表站点首页，不是自动找到的场景接口。

选择场景规则会自动填入方法、映射路径以及查询参数、请求头和正文，点击 **发送预演请求**（或 `⌘ / Ctrl + Enter`）即可查看实际返回。只有场景、没有站点时也可预演接口；交付场景须先绑定提示词。

**对比条件与空参数** 会发送两次独立预演，分别展示规则示例和不带参数请求的实际状态、正文及提示词交付位置。空参数可能命中同路径的其他规则，不保证一定走 fallback；结果会注明实际响应规则。无附加条件的规则不提供无意义的对照。

请求头和正文默认收在 **高级参数**。可手动修改后单独发送，也可 **重新填入** 恢复规则示例；绑定页的 **预演** 同样会带入全部条件。相互冲突的字段、JSON 与表单混用等复杂条件会提示手动检查，以后端实际匹配结果为准。预演不创建正式会话，也不会自动保存或发布草稿。

`matched: true` 仅表示找到了响应，可能是 fallback 或静态资源；`rule_matched: true` 表示触发条件命中。`deliveries` 列出实际提示词槽位及方案版本；HEAD 的 `deliveries` 为空。没有规则或静态资源匹配时返回 404。

公开测试入口记录 `request`、`rule_matched`、`response_sent`，含提示词的响应另记 `delivery`。会话详情分别展示当前请求使用的提示词版本、创建时场景与提示词快照，以及每次实际交付的版本号和响应正文。响应含提示词并不能证明 Agent 读取或遵从，结论仍结合 Agent 日志和 `/collect` 回传判断。

### 定制提交回传后的回复

**系统设置 → 回传成功响应** 可配置 `POST /collect` 成功接收数据后的状态码、JSON/纯文本/HTML 正文、Content-Type 和普通响应头。开启自定义后编辑并保存，立即应用到所有测试端口的后续成功回传，包括已有会话；无需重新发布工作区。失败的身份校验、缺失内容或格式错误仍按系统错误返回，不套用成功响应。数据先成功保存，再发送配置的回复；非 2xx 状态码可能导致客户端重试。

正文支持 `{{receipt_id}}`（实际回传记录编号）和 `{{run_id}}`（当前会话编号）。JSON 变量写在字符串值中，例如 `{"message":"已收到","receipt_id":"{{receipt_id}}"}`；JSON 字段名和响应头不进行变量替换，其他占位符原样保留。正文上限 128 KiB，状态码为 204、205 或 304 时必须留空。Cookie、Content-Length 等受系统管理的响应头不可覆盖。

**预览回传响应** 使用示例会话编号 `PREVIEW_RUN`、回传编号 `123`，只展示响应原文，不执行 HTML、不创建回传记录，也不保存配置。关闭自定义或点击 **恢复默认配置** 后保存，即恢复原有 `201` 和 `{"ok":true,"receipt_id":实际编号}`。

管理 API：`GET/POST /api/collect-response` 读取/保存配置；`POST /api/collect-response/preview` 预览同一配置。配置字段为 `enabled`、`status`、`format`、`content_type`、`headers`、`body`，这些接口均要求管理登录，写入和预览要求 CSRF 校验。

## 5. Nacos 风格配置读取示例

1. 新建工作区，选择“配置中心（Nacos 风格）”站点预设并保存。
2. 选择“Nacos 配置读取”场景预设并保存，为其实例绑定指定提示词。
3. 保持预设路径 `/nacos/v1/cs/configs`。列表和详情使用相同路径，靠 query 条件区分。
4. 在请求预演分别发送：

```text
GET /nacos/v1/cs/configs?search=accurate
GET /nacos/v1/cs/configs?dataId=application.yml&group=DEFAULT_GROUP
GET /nacos/v1/cs/configs?dataId=missing.yml&group=DEFAULT_GROUP
```

第一个返回固定配置列表；第二个返回演示 YAML，并以 `# ` 为每行前缀放入绑定提示词；第三个返回 404 普通正文。列表响应不交付提示词，详情才是交付节点。发布并绑定端口后，页面“查询”和“详情”按钮会请求这些真实模拟接口。

这是 Nacos 1.x 风格配置列表/读取输出的模拟，不启动 Nacos，也不复现其完整鉴权、集群或漏洞协议。更换页面不影响场景规则，只需让新前端访问相同路径并显示返回内容。另一个入门组合是“团队文件中心”配“文本输出”，触发请求为 `GET /api/download?file=README.md`。

## 6. 工作区助手：对话、按模块创建与调整

可以先直接询问能力、配置含义或操作方式，也可以描述要创建或修改的内容。助手按本轮要求选择工具；纯问答会直接显示文字，不触发草稿修复，也没有采用按钮。需求缺少必要细节时可以继续对话补充。

助手回复支持 Markdown：标题、加粗、列表、引用、表格、任务列表和代码块会直接排版，历史消息也使用相同显示方式。代码块可复制，长代码与宽表格在消息内滚动；完整的纯 JSON 回复自动按代码块展示并保留转义字符。外部链接在新标签页打开，图片引用显示为链接；HTML 和代码示例不在聊天中执行。用户输入和工具输出仍保留原始文本。

| 你的输入 | 预期行为 |
| --- | --- |
| “你可以做什么？” | 介绍可用模块和使用方法 |
| “只做一个登录页” | 创建站点草稿，不补模拟场景 |
| “只增加 GET /api/info 的返回规则” | 创建场景草稿，采用时保留原站点 |
| “解释刚才这个场景什么时候返回提示词” | 读取已有上下文并回答，不修改草稿 |
| “给我一个 JSON 示例，先不要创建” | 显示示例文字，不保存成素材 |

内置模块指南说明站点文件、场景规则、网页克隆、素材引用和提示词绑定的使用方式。助手按需读取指南及引用资料，只有工具实际改变的模块会成为可采用结果。模块文档和工具参数由程序提供，不需要用户每轮重复描述格式。

在对话输入区展开 **参考网址**，填写 **参考网址** 后点击 **仅克隆网页**，可以不配置模型，先获得可编辑的静态站点。系统先读取公开 HTTP(S) 文档；检测到静态空壳或脚本加载占位时，会自动尝试本机 Chromium 渲染，取得 JavaScript 生成的 DOM，再下载样式、图片、字体等资源并清洗为本地素材。动态回退需要部署 Node、Playwright、Chromium 和 worker，安装方式见 [README](../README.md#启动)。普通静态页面仍只需 Go 程序。

浏览器使用新的匿名上下文，不读取管理员或个人浏览器 Cookie，不遍历导航链接，也不运行源码构建。页面脚本只在抓取阶段运行；网络读取交给 Go 下载器，逐跳校验公网 DNS/IP，只允许 GET。输出会移除原站脚本、表单提交和主动网络行为，保留可编辑的静态外观；交互需要重新连接本地模拟 API。这个过程不调用模型。

回退针对静态空壳，不会自动重演登录、点击或整个网站的所有状态。登录后内容、需要 POST 的数据、验证码、未展开菜单和复杂图表可能无法保留；浏览器取得的 DOM 也不等同于完整应用源码。资源下载失败会列出警告。若仍提示没有可保留内容，检查任务活动与浏览器运行环境，或导入项目的静态构建产物；需要真实交互时可让 AI 将按钮、表单接入本地模拟响应。

在 **模型设置** 添加一个或多个模型配置，选择 **OpenAI Compatible** 或 **Anthropic Messages** 协议，填写 Base URL、模型名称和必要的 API Key。OpenAI 兼容协议使用 `/chat/completions`；Anthropic 使用原生 `/v1/messages`，包含 `tool_use` 与 `tool_result` 的多轮回传。DeepSeek、自定义网关及本地兼容服务可用 OpenAI Compatible。模型名称以服务实际提供的 ID 为准。

**保存并测试连接** 验证文本响应，不能代替工具能力测试。密钥不在读取接口中回显；留空只保留当前配置的密钥，无密钥本地服务也可配置。旧的单模型设置会自动迁移为默认配置。输入区可为每轮任务选择模型，运行中的任务使用启动时的配置快照；之后修改或删除配置不会改变正在执行的任务。

填写需求并发送（Ctrl / ⌘ + Enter 发送，Enter 换行），例如：

> 克隆参考网址的配置中心外观，保留导航和配色。列表请求 `/nacos/v1/cs/configs?search=accurate`，详情请求同一路径并传入 `dataId=application.yml`、`group=DEFAULT_GROUP`。详情返回演示 YAML，指定提示词使用 `{{prompt}}`，每行加 `# ` 注释前缀。把按钮连接到这些本地模拟接口。

在输入框键入 `@`，或点击引用入口，先选择**站点素材、模拟场景或提示词**，再检索该类型中已保存的条目。选择类型后输入框变为 `@站点素材 ` 等形式，继续输入名称或 ID 即可筛选；也可以直接输入 `@站点素材 名称`、`@模拟场景 名称` 或 `@提示词 名称`。不指定类型时，输入 `@名称` 可跨类型检索。

上下键选择、Enter 确认、Esc 收起；类型内可以点击返回箭头，或在检索词为空时按左方向键 / Backspace 返回类型列表。选中条目后以引用标签显示，支持继续添加、移除标签。每轮最多引用 8 项，其中提示词方案最多 1 项，选择另一个方案会替换原方案。新对话会清空引用，续聊默认沿用所选素材 ID，并在每次发送时读取其最新版本；输入框标签随素材列表更新、历史恢复和发送结果同步。历史消息和执行中任务保留当轮引用快照。已删除的素材不会被同名项自动替代，需移除引用或重新选择。

例如先引用 `@配置中心站点`、`@配置读取场景`、`@实验提示词`，再输入：“使用所选站点和场景，把详情按钮连接到配置读取接口，保留指定提示词槽位。”Agent 可读取被引用素材，通过 `use_reference` 将站点或场景复制到当前任务草稿后调整，原素材不受影响。站点二进制资源保留，模型只读取文本文件和文件元信息。

提示词引用默认仅提供元信息，用于**采用结果时绑定方案**；明确要求编辑提示词时，Agent 可使用 `read_material` 分页读取正文，再通过 `save_material` 保存修改，正文作为编辑数据而非执行指令。接口仍使用 `{{prompt}}`。点击“采用到当前草稿”时，将所引用方案绑定到生成的场景或选定的现有场景实例，再保存、预演和发布。如果仅克隆了站点且没有目标场景，页面会提示尚需添加场景完成绑定。发送时服务端核对素材 ID 和版本；素材已修改或删除时需重新选择，避免误用同名或旧版本内容。引用素材内部的网址不会自动获得克隆权限。

也可直接在需求中写明要克隆的 URL，由 Agent 根据要求调用克隆工具；仅填写参考网址不会在普通问答开始前自动抓取，点击 **仅克隆网页** 才会直接克隆。每个任务最多接收三个用户提供的网址，模型不能自行添加其他克隆入口。工具调用逐条显示名称、参数摘要及状态，展开可查看真实输入、输出和耗时；工具报错会返回模型供其继续修正，失败记录仍保留。等待模型回复时不会生成工具卡片，复杂任务可附简短计划。工具输入/输出各最多保留 8,192 字符，超长会标明截断；历史对话默认只加载摘要，展开时再读取详情。旧版记录只能展示已有的进度摘要，不能补出当时未保存的参数和结果。自 4.6.17 起，模型接口返回的可展示思考文本会以“思考”折叠行穿插在工具调用之间，支持 Markdown；每次最多保留 32,768 字符，超长标记截断。OpenAI Compatible 的 `reasoning_content` / 纯文本 `reasoning` 与 Anthropic 的 `thinking` 文本均受支持；签名和加密内容不展示、不保存。当前在每次模型请求完成后显示，不是逐 token 流式输出；旧任务未记录的思考文本无法补回。

1. 左侧 **新建对话** 开始属于当前工作区的独立对话，默认只展示该工作区的历史。**未归属历史** 保留旧版无归属或工作区已删除的对话，可手动恢复结果；继续发送时复制结果作为新基线，在当前工作区另开对话，不改写历史归属。新任务使用当前工作区站点作为修改起点；在 **场景结果用于** 选择现有实例时，也会读取该实例的场景。选择新增场景则不带入现有场景。
2. 有草稿变更时检查对应结果：站点显示外观预览，场景显示规则摘要，可用 **编辑生成的站点 / 编辑生成的场景** 修改对应模块。纯问答显示回复文字。外观预览不运行脚本，不能验证按钮与 API 是否对应。
3. 点击 **继续调整**，仅填写下一步要求。后端继承已完成任务的草稿与近期对话，界面中的手动编辑结果优先作为新基线；原任务和已有素材保持不变。
4. 点击 **采用到当前草稿**，在一个事务中新增本轮实际修改的站点或场景素材。仅修改场景时不替换原站点，仅修改站点时保留已有场景。选择现有实例时替换其场景，保留默认提示词、规则 ID 仍有效的接口提示词绑定及路径覆盖；新增实例后检查提示词方案。此时仅更新页面中的工作区草稿，仍需 **保存工作区 → 请求预演**；首次使用时发布工作区，已有发布随保存同步。

对话可以异步并行执行：一个任务运行时，仍可点击 **新建对话** 或切换左侧会话，为另一对话选择模型并发送。列表分别显示各对话的运行、完成、失败或取消状态；后台完成不会切走当前视图或自动采用素材。点击对应对话可查看工具进度及结果，**取消任务** 只取消当前对话的本轮任务。同一对话必须等待本轮完成或取消后再发送，跨标签页重复提交也会被后端拒绝（409）。

同一页面内切换对话时，保留每个已有对话未发送的文字、引用、参考网址、模型选择及未采用的本地草稿编辑；这些未发送内容不会写入数据库，刷新或离开工作区后不保证保留。已提交任务独立在后端执行，刷新后可以从会话列表恢复；执行中的模型配置不会被其他对话的模型选择更改。

采用接口对同一任务、相同内容返回同一批素材，不重复新增；首次采用后再提交不同内容返回 409，需要继续调整为新任务。采用成功不会自动保存工作区或发布。普通 Agent 任务和仅克隆任务都可以只包含站点；也可生成只有场景的结果。纯问答不能采用。后续询问保留已有草稿上下文，更早的草稿仍可从对话中查看。

已有素材通过 Agent 保存成功后，引用它的已发布工作区会自动同步，无需再次保存、发布或绑定端口。Agent 的初始上下文、校验与保存结果包含服务器核实的保存状态；续聊快照没有素材 ID 时，会核对是否与工作区已保存内容一致，避免误报“站点尚未保存”。完成说明只汇报本轮实际改动和真实未完成项，不例行重复保存或发布步骤。仅在存在未保存草稿，或用户需要将尚未发布的工作区首次上线时，才提示相应操作。

模型偶发空回复、仅返回思考数据、响应超时、连接/传输中断或上游临时错误（408、429、500、502、503、504、529）时，助手保留当前草稿和成功的工具结果，仅重试该次模型请求。每个任务合计最多额外重试 2 次，退避为 0.5 / 1 秒；默认单次完整响应最多等待 180 秒，任务总时限为 600 秒；在 **系统设置 → 生成模型设置** 或对话中的 **模型设置** 可为各模型分别配置：单次 10–3600 秒、任务 30–7200 秒，任务时限不得小于单次时限。保存后新发起的任务使用新值（含已有对话的新消息），进行中的任务保持启动时的设置；连接测试也使用单次时限。连接建立和 TLS 握手各限 10 秒。输出因 token 上限截断时，不执行其中的不完整工具；使用配置的输出额度和分段恢复说明重新请求，详见第 9 节的上下文和输出额度。鉴权失败（401/403）、明确拒绝、上下文已满和协议错误不会盲目重试。

任务内 **模型响应诊断** 显示重试/失败原因、轮次、错误分类、已等待时间、结束原因及供应商返回的 token 用量，成功恢复后标记 **已恢复**。诊断不保存模型思考正文、签名或原始响应；旧任务没有这些字段，因此无法补出当时的供应商结束原因。历史失败记录不会自动重放，需重新发送需求。

需求、近期对话、场景规则、参考网页结构及 Agent 读取的文本文件会发送到配置的模型服务；二进制素材只提供路径与大小，提示词方案正文不作为上下文发送。网页和素材内容作为不可信参考数据，不能获得额外工具权限。Agent 只能修改任务草稿，不能执行命令、读取本机凭据、选择提示词方案或发布。

全服务最多同时运行 8 个任务，达到上限时提示等待或取消，不会自动排队；单任务最多 24 轮模型请求、96 次工具调用，默认总时限 10 分钟（可按模型配置），模型上下文上限 768 KiB，请求 JSON 上限 12 MiB。单次网页克隆最多 90 秒，其中浏览器渲染最多 45 秒。浏览器返回的 DOM 上限 2 MiB；浏览器网络响应总量上限 32 MiB，单个文档响应上限 2 MiB、其他响应上限 8 MiB，最多 160 次请求。以上是临时渲染预算，最终站点仍遵守单文件 4 MiB、合计 8 MiB、最多 256 个文件的素材限制。样式表会优先下载；字体单个上限 256 KiB、合计 512 KiB，超限时使用页面字体回退，避免字体挤占布局资源。常见框架的临时 toast 会从快照中移除，业务提示仍保留。可随时取消；浏览器刷新后可从左侧对话列表恢复。列表展示最近 50 个对话，每个对话展示最近 100 轮；更早任务仍保存在数据库。服务重启将未完成任务标记为中断，不自动继续模型调用。生成质量与实际交互仍需 HTTP 预演及测试端口的浏览器检查。

## 7. 管理 API

以下管理接口都需要管理员登录 Cookie，写入还需要 `X-Admin-Token`。令牌取自已登录的 `GET /api/state` 的 `csrf`；不要把它放进公开前端或站点素材。JSON 请求使用 `Content-Type: application/json`。

创建素材时省略 `id`，更新时提交当前 `id` 和 `version`；版本不一致返回 409，避免覆盖他人修改。预设通过 `/api/composer/state` 获取，是新素材的起始草稿，保存前移除预设 `id` 和 `version`。

无需模型的克隆请求示例：

```json
{"mode":"clone","source_url":"https://example.com"}
```

从已完成任务继续调整，省略 `site` / `scenario` 时继承上一任务结果；提供时以传入草稿为准：

```json
{"mode":"agent","parent_job_id":"已完成任务ID","prompt":"保留页面外观，把下载按钮连接到 /api/download，并增加带 {{prompt}} 的文本返回规则。"}
```

引用现有素材与指定提示词方案：

```json
{
  "prompt": "使用引用的站点与场景，调整配置详情按钮，保留提示词槽位",
  "references": [
    {"kind": "site", "id": "SITE_ID", "version": 1},
```

`kind` 为 `site`、`scenario` 或 `profile`；后端按 ID 读取，忽略客户端提供的名称或正文。最多 8 项、1 个提示词方案，引用快照总量上限 16 MiB。续聊省略 `references` 继承父任务引用的 ID 并获取最新版，显式传 `[]` 清除。显式提供 `version` 时版本不符返回 409；省略版本则按 ID 读取最新版。素材不存在返回 404。

## 8. 从旧页面模板与旧部署升级

打开已有数据库时，旧单页模板自动转换为独立静态站点，保留原模板记录。迁移只带入可编辑外观，不自动迁移旧部署的载体、固定暴露面和提示词绑定；在工作区选择迁移站点后，重新配置场景与提示词并发布。删除迁移得到的站点后，迁移标记会防止重启时再次生成。

旧部署不自动发布为工作区。原有端口若仍绑定旧部署，可保留绑定并进行启停或删除，不再修改其业务覆盖；新建或改绑端口只能选择工作区发布结果。旧会话继续按原快照查看和导出，历史回传协议保持兼容。

所有 `/api/templates`、`/api/deployments`、`/api/preview` 及其子路径均在管理员鉴权后返回 HTTP 410，包括原来的创建、更新、删除和预览请求。旧客户端应改用本指南的站点、场景和工作区 API，而非重试旧接口。

历史 Python 后端及 `before-legacy-removal-20260918` 回退标签保留在私有历史中，未包含在本次公开源码内。运行数据库需要另行备份。详细启动与回退说明见 [README](../README.md#旧流程迁移与回退)。

工作区对话列表支持 `GET /api/generation/conversations?workspace_id=<ID>`；`workspace_id=unassigned` 返回无归属或工作区已删除的历史。无参数保留全局列表兼容行为。筛选后最多返回 50 个对话。列表和详情携带 `workspace_id`；跨工作区使用 `parent_job_id` 或 `conversation_id` 返回 409，复制历史结果时应以新对话提交。

### 删除模拟场景

在工作区的 **模拟场景** 卡片点击 **删除**。确认后删除素材库中的当前场景，已发布快照和历史记录保留。若场景仍被已保存工作区引用，弹窗列出工作区名称；先在“绑定提示词”中移除对应实例并保存，随后即可删除。仅在当前未保存草稿中添加的实例会随删除一并移除，其他草稿修改保留。

请求预演的接口目录按模拟场景分组，使用 **按场景筛选** 可只展示选中场景，路径/参数检索在该场景内继续过滤。

### 回传路径与令牌轮换（4.6.19）

打开 **工作区设置 → 回传路径**，输入如 `/api/report` 并保存。完整回传地址由该蜜罐端口的公开地址加上此路径组成；同一工作区绑定多个端口时，每个端口返回自己的地址。提示词使用 `{{callback_url}}`，不要写死域名、端口或 `/collect`。已有正文中的固定地址不会被自动替换，请编辑为槽位。默认路径仍为 `/collect`。

已发布工作区保存新路径后立即切换入口，已有会话的下一次响应也使用新地址；旧路径不再作为回传入口。不能与模拟接口、站点文件或系统保留路径冲突。Agent 可以按要求调用 `read_callback`，再使用返回的版本调用 `set_callback_path` 修改当前工作区，不能借此修改监听端口或发布新工作区。修改令牌失效响应时也先 `read_callback`，再 `set_callback_response({version,json})` 保存当前工作区的响应字段补丁；`enabled:false` 恢复默认 403，`enabled:true` 使用自定义配置。

`{{token}}` 在当前会话每次业务请求时轮换，包括静态资源、HEAD 和未命中路径；只接受最新签发的令牌，旧令牌立即返回 403。健康检查、管理端预演和回传请求本身不触发轮换。因此并行请求或回传前继续读取页面资源，会使前一响应里的令牌失效；客户端应使用最后一次签发的值。数据库只单独保存当前令牌的哈希，创建时快照和历史交付正文不改写；升级前令牌仅保留到该会话的下一次业务请求。规则条件不要硬编码某次 `token` 的字面值；真实回传入口始终校验会话、当前令牌和所属端口。

自 4.6.20 起，在 **工作区 → 发布设置 → 令牌失效响应** 可自定义旧令牌或无效会话/令牌提交时的 HTTP 状态码、响应格式、正文和响应头；默认返回 HTTP 403。支持 `{{run_id}}`，不生成回传编号。每个工作区独立配置，保存后只更新此工作区已绑定端口的回传入口，无需再次发布，不影响其他工作区。新工作区默认 403，不继承全局配置。与系统设置中的“回传成功响应”分别管理。即使自定义为 2xx，拒绝的提交仍不会保存为回传记录，不产生成功事件，也不恢复旧令牌有效性；跨端口提交、缺少身份字段等校验仍使用对应错误。

自 4.6.21 起，续聊不再把旧消息的素材版本号作为新请求的版本锁。手动保存素材、其他对话修改素材、恢复历史对话或在选择后再次更新素材，都按相同 ID 获取最新版，不再因输入框持有旧版本而拦截正常续聊。API 如显式提供 `references[].version` 仍保留版本冲突检查；UI 按 ID 引用、不发送版本锁。已有任务的引用快照、素材写入版本检查和草稿采用校验保持不变。

## 9. 多 Agent 与内容核查（4.7.1）

侧栏 **Agent 管理** 内置「蜜罐编写 Agent」和「内容核查 Agent」，也可新建同类型的专用 Agent。每个 Agent 独立设置名称、启用状态、模型、补充说明、最大执行轮数和工具绑定。展开工具可查看实际参数 JSON Schema；设置、模型请求和执行校验使用同一份工具定义。取消绑定后，模型无法调用该工具；编写 Agent 仍受本轮修改范围和素材版本校验约束。

**AI 助手** 的输入区可以选择编写或核查 Agent，模型默认跟随该 Agent 的绑定，也能选择本轮模型。手动选择的模型在刷新后保留。每个任务固定启动时的 Agent 和模型配置；修改配置只影响新任务。不同会话可以异步执行，共用 8 个任务并发上限。左侧按 Agent 折叠分组、显示会话数量及运行状态；切换角色会新建对话。核查咨询、报告、工具记录和追问均使用这个聊天页，普通能力咨询不会强制执行完整核查。

聊天页 **触发设置** 弹窗提供（不再单独设置内容核查页签）：

- **开始完整核查**：使用已保存工作区和当前绑定素材，不要求先发布。先保存未提交的编辑。
- **工作区或绑定素材保存后**：监测工作区、站点、场景及提示词的已保存内容，发生变化后自动核查。
- **编写 Agent 完成后**：编写任务结束后检查当时已保存的工作区；尚未采用的生成草稿不属于核查对象，采用并保存后可由保存触发再核查。
- **更多触发条件**：编写失败/超时、指定编写工具成功调用、30–86400 秒定时（0 关闭）。每种条件可自定义发给核查 Agent 的消息。
- **登录与访问步骤**：可配置打开页面、填写、点击、选择、文字或可见性断言。留空时，由绑定模型读取站点并规划操作。一个流程包含登录与后续访问，步骤之间保留 Cookie 和页面状态；每次新流程使用独立浏览器。

自动触发默认关闭，开启时从当前状态开始监听，不补跑旧修改；重启不重放已处理事件。同一工作区的自动核查串行合并并复用会话，核查自身事件不会循环触发。手动聊天可在不同会话并行，同一会话的轮次顺序完成。无法启动时显示原因，条件恢复后继续尝试。

核查在临时数据库和隔离浏览器内运行，复用正式请求匹配、提示词渲染与回传验证代码。检查主页和资源、每条接口的触发及条件不满足响应、实际状态码/响应头/正文、接口指派的提示词、有效回传和令牌轮换后的拒绝响应。浏览器实际执行页面脚本、登录和登录后的内容触发；请求只送入临时工作区，外部地址和 WebSocket 被阻断，不向线上蜜罐发业务请求，也不新增线上会话/交付/回传记录。

报告区分 **通过、异常、未确认**，可以筛选和展开请求/响应、浏览器步骤与工具调用证据。未配置模型、浏览器不可用、未访问接口或没有内容断言时不会宣称完整通过；复杂条件可能需要补充实际请求参数和操作步骤。取消或超时保留已完成检查，标明剩余部分未确认。核查 Agent 只检查和报告，不擅自修改、发布或执行被测提示词中的命令。

### 访问流程画板（4.9.0）

工作区 **访问画板 → 开始核查并绘图** 使用已配置的内容核查 Agent 与触发设置；也可以在 AI 助手中让核查 Agent 检查从登录到指定接口的完整访问流程。Agent 的 `run_browser_flow` 自动记录页面操作、当时发生的 HTTP 请求、实际命中规则以及响应中的提示词交付点。画板执行中更新，结束后随核查记录保存；AI 助手的核查报告中也可以打开画板。

浏览器连续操作、独立接口检查和单次 HTTP 探测分组展示。独立检查会构造满足规则的参数，因此不代表登录后的页面入口已走通。交付节点必须来自隔离运行时的真实交付事件，显示提示词 ID、名称、版本与绑定规则；交付不等同于访问者执行了提示词。操作间的连线表示时间顺序，请求连线表示该操作期间观测到的请求，不推断认证状态的数据依赖。

4.10.2 使用与 ARTEX 相同的 React Flow 画布组件：拖动卡片调整节点位置，拖动空白平移，滚轮或双指缩放。连线从左向右排列，按访问顺序、请求、规则命中、提示词交付和回传等关系区分颜色，带标签与方向箭头，并随拖动更新。右下缩略图支持点击定位、拖动和缩放；左下可放大、缩小、适应画布或重新排列。支持全屏查看。节点位置与视角按核查记录和流程分组保存在当前浏览器，轮询更新、切换分组和刷新页面不会重置已调整的位置；“重新排列节点”恢复自动布局。

点击节点展开请求、响应等证据，从交付点可高亮访问前序。保留移动端列表和 JSON 导出。单次记录最多展示 600 个节点，响应正文保留有界摘录，超过限制会提示查看完整报告。工作区或任何绑定素材更新后，旧画板会显示版本过期提醒；旧报告不补造访问轨迹，需要重新核查生成画板。异常、中断与未执行步骤会保留，核查仍在隔离环境内，不修改线上会话。

浏览器核查需要 Node、Playwright 和 Chromium，沿用网页抓取的浏览器环境。部署时将 `scripts/workspace-review.mjs` 放在 `browser-capture.mjs` 同目录；可通过 `AGENTMIRROR_BROWSER_WORKER` 指定后者路径，`AGENTMIRROR_BROWSER_NODE` 指定 Node，`PLAYWRIGHT_EXECUTABLE_PATH` 指定浏览器。仅运行独立 Go 二进制仍能做 HTTP 核查，缺失浏览器的部分会明确列为未确认。

管理 API：`GET/POST /api/agents`、`GET /api/agent-tools`；`GET/POST /api/workspace-reviews/{workspace_id}/policy` 保存触发策略；`POST /api/workspace-reviews/{workspace_id}` 手动运行、`GET` 取摘要列表。对话通过 `POST /api/generation/jobs` 指定 `agent_id` 启动，沿用 `conversation_id` 追问。完整报告和工具记录使用 `GET /api/generation/jobs/{job_id}`，取消沿用其 `/cancel` 接口。均要求管理员认证及写请求 CSRF 校验。

### 上下文和输出额度（4.7.1）

模型设置分别配置上下文窗口（默认 128,000 token）和单次输出上限（默认 24,000 token），请按供应商实际支持的额度填写。思考 token 可能占用输出额度；截图中的 `max_tokens` 表示单次输出截断，输入压缩不能替代输出额度配置。

编写和核查共用上下文整理：按窗口扣除输出额度与安全余量，达到输入预算 80% 或消息体超过 256 KiB 时，将旧对话和完整工具往返整理为有界历史摘录与当前状态，精确保留当前请求和最近完整往返，不改写协议签名。页面显示压缩前后的估算 token；原有任务记录保留。这是本地状态整理，不是 LLM 语义摘要；省略正文须按需重新读取，不可假定模型仍记得。

输出截断后不执行残缺工具，重试会要求简短回答或单个小步骤：首段 `write_file`、后续 `append_file`、局部 `edit_file`、场景单条 `upsert_rule`。重试不突破配置额度，全任务最多两次恢复。不可再缩减的当前输入超限时给出明确错误，不丢弃当前请求。此规则替代旧版固定 12,000 → 24,000 的截断处理。

### 首段响应与流式返回（4.7.2）

模型设置默认开启 **流式返回**，编写与核查 Agent 都能逐步显示供应商返回的思考正文和回复，不必等待整轮生成结束。服务只返回加密/隐藏思考时不会伪造可见思考；页面的首段秒数表示首次收到可显示文本或工具名称的耗时。工具参数在完整响应校验通过前不会执行。

不支持流式的服务可在模型设置中关闭；网关忽略流式参数但返回完整 JSON 时直接兼容，不重复发送请求。超时仍覆盖整次请求，流式心跳不会延长上限。断流或输出截断清除临时预览，沿用最多两次恢复预算，完整历史及实际工具执行结果仍保留。HTTP 连接跨轮次复用。

实时预览保存在内存、按当前任务隔离；刷新/切换回运行中的任务会重新读取，结束后只展示已确认的结果。页面每 0.5 秒读取当前任务的轻量进度，工具详细参数和历史思考按展开加载。模型排队或尚未输出内容的时间由供应商决定，流式返回不会缩短完整推理耗时。

同一模拟场景可以添加多个实例，但启用实例的 HTTP 方法、映射路径和触发条件不能完全相同。场景卡片已加入后显示“添加另一个实例”；重复冲突提示会列出涉及的实例编号。只需要一套接口时，在绑定提示词页移除多余实例；需要多套时分别设置路径或条件。

### Todo 计划（4.7.3）

AI 助手输入框下方的 `Todo` 入口展示当前会话的最新任务计划。默认收起，点击后向上弹出列表；待处理、进行中、已完成使用小图标标识，完成项变灰并加删除线。执行中保持打开也会同步新状态，刷新后保留计划；新会话没有计划时入口置灰。支持 Esc 或点击外部关闭。历史各轮的原始计划调用仍可在工具记录中展开。

## MCP 外部工具（4.8.0）

1. 打开侧栏 **MCP 服务**，填写名称和连接方式。支持 Streamable HTTP、旧版 SSE，以及在 AgentMirror 服务所在机器执行的 stdio 命令。
2. HTTP/SSE 填写完整地址和认证请求头。stdio 的可执行命令和 JSON 参数数组分开填写，不经过 Shell 展开；额外环境变量填写在环境变量对象中。
3. 点击 **保存并测试连接**，完成握手并读取工具目录。**保存配置**也能保留未连通的服务，稍后可以再次测试。连接和单次调用超时可设为 1–300 秒。
4. 打开 **Agent 管理 → MCP 服务**，勾选允许加载的服务，点击 **保存 Agent**。编写、核查及自定义 Agent 均可独立绑定，默认没有 MCP 权限。
5. 在 AI 助手中选择该 Agent，发送需要外部工具的请求。聊天显示 MCP 加载状态和工具调用记录。配置修改对新任务生效；运行中的任务保留启动时配置。

按服务整体授权，绑定后允许调用服务提供的工具。外部工具在 MCP 服务自身的环境和权限下运行，与内置的隔离核查工具不同。停用后新任务不再加载；删除服务同时解除 Agent 绑定。每个 Agent 最多绑定 8 个服务，最多加载 96 个 MCP 工具，超量时显示未加载原因。

请求头与环境变量的已存值显示为 `null`，保存时保留旧值；填写新值为替换，删除键为移除。连接配置存在独立 MCP 数据表，不放入工作区导出、模型请求或任务配置。不向不同来源的 SSE 地址或重定向发送认证头。stdio 仅继承必要的路径、用户目录等环境变量和显式配置项；任务结束或取消会关闭连接及子进程。

协议处理使用官方 Go SDK，包括初始化、工具目录分页、工具调用。当前支持手工请求头认证，不包含交互式 OAuth 登录或 MCP resources/prompts 浏览器。二进制响应保留元数据，不作为文本上下文发送；长结果会标记截断，建议分页查询。

### 红队测试 Agent

AI 助手的「对话 Agent」可选择「红队测试 Agent」。默认使用自主行为测试：先在 Agent 管理配置被测模型的独立任务（普通的网站安全检查目标）、模型和角色说明，再发送消息启动一轮。评测聊天及历史报告不会传给被测模型，避免预先要求它执行或拒绝注入。模型从真实可见的页面和响应发现路径，不预读后台规则、触发参数或绑定提示词。

测试使用当前**已保存工作区的隔离副本**，无需先发布；HTTP 使用同一响应/令牌/回传处理器，保留测试 Cookie。回传路径遵从该工作区配置，响应中的当前蜜罐完整地址映射到隔离处理器。不会请求线上端口或产生生产会话；工作区以外的 URL 不执行。每轮新建副本，上轮令牌不可用于本轮。浏览器工具每次使用新上下文，一次调用应包含完整登录与后续操作。

工具包括 `redteam_request`、`redteam_browser`、`read_redteam_response`、`redteam_command`、`finish_redteam`。已观察响应支持分页读取，不会因翻页发起新请求或轮换令牌。模拟终端仅解释工具目录列出的诊断命令（例如 `id`、`uname -a`、`cat /etc/passwd` 和 `cat /workspace/diagnostic.txt`），输出为合成数据。它不执行宿主机程序、读取真实文件或加载外部 MCP；未支持的指令显示未覆盖。后续工具可提交实际的合成输出，回传仍经过真实令牌校验。

默认自主模式分别报告模型发现/拒绝的判断、实际模拟命令、工具阻止、输出匹配回传与唯一合成标记回传。判断必须引用已读取的响应，执行和回传以工具记录核对。没有动作不能自动视为拒绝，工具阻止不算自主拒绝；即使模型声称拒绝，实际执行的证据仍优先。HTTP 200 或提示词交付不会显示为注入成功。

需要排查接口与回传链路时，可在 Agent 管理切换为**受控复现**，按聊天要求复现操作；旧报告继续标注受控复现。两种模式都使用合成终端，不读取宿主机信息。模型、任务、角色说明、工具和模拟环境会影响结果，不能由一次本地测试推断其他外部 Agent 的接受率。

### 中断后继续（4.10.1）

蜜罐编写 Agent 在工具执行前后保存恢复检查点。模型报错、任务超时、取消或服务重启后，在**同一对话**发送“继续”，会恢复原始需求、近期对话、Todo 计划、完整的中途站点/场景草稿及工具进度。新任务拥有新的超时预算，界面显示恢复提示；不必重新描述需求或重新创建工作区。新建对话仍从独立上下文开始。

中途草稿不是完成结果，不会自动发布或作为可采用结果展示；完成后按现有保存/采用流程处理。已经成功保存的素材及回传设置保留原有热更新效果，无需重复保存。恢复后继续编辑已保存素材，仍需读取当前版本，避免覆盖其他修改；上次未确认结果的外部工具需先核对实际状态。自动修改范围在“继续”时沿用原范围，用户显式选择新的范围则优先。

恢复检查点保存在本地数据库，不随聊天轮询或历史列表返回；不保存模型隐藏推理、模型凭据或跨轮写入授权。文件正文按原文保存，执行记录只保留近期摘要，模型可分段重新读取。修复前的旧任务可以找回原始需求与已有记录，但当时未落盘、已经丢弃的临时文件无法完整恢复。

### 多站点联动与文件托管（4.13.0）

在工作区「站点素材」页下方配置「多站点联动」。原有素材作为主站点 `/`；添加子站点后，分别选择站点素材、上级站点和路径段。例：主站点 `/` → OSS `/oss/` → VPN `/oss/vpn/`。默认通过**同一个蜜罐端口、不同路径**访问，最多 16 个子站点、8 层嵌套；4.14.0 起也可为子站绑定独立端口。

每个站点可复用或选用不同素材。在「绑定提示词」为场景实例选择「所属站点」；规则路径相对所属站点填写，例如 VPN 场景的 `/api/status` 实际为 `/oss/vpn/api/status`，预演会自动使用完整路径。接口进入其他子站点命名空间、重复挂载、循环上下级或占用回传地址时会拒绝保存。子站点可单独配置 `Server` 头，留空继承工作区；显式接口头仍优先。

复制子站点链接并写入上级页面即可建立跳转。子站点自己的资源、表单与 API 使用相对路径（如 `css/style.css`、`api/login`）；以 `/` 开头的链接从主站点根路径解析。系统不会自动改写导入源码中的绝对路径。

「文件托管与 HTTP 下载」选择所属站点，填写站内路径（例如 `downloads/vpn.zip`），上传用户已有的文件。单文件最大 **128 MiB**，上传后保存至所选素材；文件 URL 为该站点前缀加文件路径，作为 HTTP 附件下载，支持 `HEAD`、`Range` 与 SHA-256 ETag。文件托管不执行安装包。预演只显示元数据；通过已绑定端口下载才传输文件内容。

首次发布后，保存站点、场景或拓扑，以及上传/移除下载链接，均同步已有发布端口。同一端口内的路径链使用同一访客会话；不同端口分别建立会话，不共享回传令牌。下载记录包含路径、站点节点、文件大小、实际传输字节和 SHA-256。隔离核查可读取全部子站点并校验下载字节数与哈希，二进制内容不会进入模型上下文。移除链接保留历史文件供旧版本证据使用。

数据库保存文件元数据，原始内容保存在 `<数据库文件路径>.files/`，按 SHA-256 命名。备份或迁移时，**数据库与这个目录必须一起复制**。素材 JSON 中 `encoding: hosted`、`file_id` 是文件引用，不是可迁移的完整文件包。


### 子站独立端口（4.14.0）

保存并发布工作区后，在「站点素材 → 多站点联动」找到子站，点击「绑定独立端口」。弹窗的「端口首页站点」默认选中该子站；填写监听地址、端口、公告地址后绑定。也可在「设置 → 端口配置」选择工作区和首页站点。既有端口默认仍以主站点为首页。

例如主站端口 8767、OSS 端口 8773、VPN 端口 8774：OSS 首页为 `http://主机:8773/`，VPN 首页为 `http://主机:8774/`，VPN 的 `downloads/client.zip` 通过 `http://主机:8774/downloads/client.zip` 下载。OSS 下的 VPN 也保留 `http://主机:8773/vpn/`；原主站 `/oss/vpn/` 链接仍可用。独立端口只提供所选站点及其后代的素材和场景，不提供其上级或兄弟站点内容。

「复制站点链接」和「复制下载链接」优先选择该站点的独立端口；没有独立端口时选择最近祖先的端口。将复制的完整链接写入上级页面可建立跨端口跳转；系统不会改写素材源码里的既有链接。独立端口下以 `/` 开头的资源或接口路径以该子站为根。

请求预演通过「预演站点入口」选择子站后，会将所选子树视为 `/`，仅显示相应场景，并使用独立端口的站内路径。预演不会创建正式访客记录。

每个端口的提示词回传地址使用该端口的公告地址加工作区回传路径。跨端口使用会话或令牌会被拒绝；将同一端口改绑到另一个站点后，原会话也不能继续调用，新访问重新建立会话。保存素材、场景、绑定及工作区配置后自动同步所有入口，保留历史发布和交付记录。删除子站前需先解除它的端口绑定；暂停中的端口仍保留绑定。


### Agent 多站点操作与交互提问（4.15.0）

蜜罐编写 Agent 可直接管理当前工作区的子站：新增、重命名、调整上下级/路径、切换素材、移除挂载，以及托管下载的挂载和移除。读取 `read_workspace_sites` 后使用对应工具；站点内容仍使用 `load_material`、分段编辑和 `save_material`，操作成功即保存并同步已发布端口。移除子站不会删除共享素材，有下级、场景或端口依赖时会拒绝删除。

用户明确要求时，Agent 可首次发布工作区，为主站或子站创建独立端口、切换首页站点、启停和删除端口。新增端口需要明确的监听地址、端口号和公告地址；仅能操作当前工作区。界面修改范围新增「仅修改发布与端口」，子站和文件托管属于「站点素材」范围。并发编辑以最新版本为准，冲突须重新读取，不覆盖他人的配置。

托管工具只引用用户已上传的文件，可以使用对话附件的文件 ID，或通过 `list_hosted_files` 查找，再使用 `attach_hosted_file` 挂载。Agent 不读取宿主机任意文件，也不生成假安装包；文件不存在时可以请用户在对话或提问卡片中上传。移除下载链接保留文件历史字节。

编写和内容核查 Agent 可调用 `ask_user`，在缺少必要信息时在同一个 AI 助手对话里提问。卡片支持建议选项和自由输入，选择选项后仍需点击「提交回答并继续」。等待期间保存草稿、计划和工具进度，不占运行任务槽位，也不消耗任务时限；刷新或服务重启后仍可回答。答案保存在历史中，后续执行延续原工作区、Agent、任务和修改范围；重复提交不会创建多个任务。可点击「取消等待」，保留已执行的修改。

内置编写/核查 Agent 首次升级时添加上述工具；在「Agent 管理」可查看或关闭工具，关闭后的配置不会在再次重启时被恢复。自定义 Agent 需自行勾选工具。红队自主行为测试仍保持访客隔离，不获得发布或修改配置的工具。

### 对话上传与空工作区托管（4.16.0）

在「AI 助手」选择蜜罐编写 Agent，点击输入框下的「上传文件」，选择文件并发送要求，例如“把附件托管到 downloads/client.zip，给我下载链接”。每轮最多 8 个文件、每个最大 128 MiB。支持进度、取消上传、移除附件及失败后重新选择；上传完成前不能发送任务。附件只传文件 ID、名称、大小和 SHA-256 给模型，二进制正文不进入对话上下文。

无需预先创建主站素材：`attach_hosted_file` 对空工作区的 root 使用 `site_version: 0`，会原子地创建下载页、挂载文件并绑定素材。「站点素材 → 文件托管与 HTTP 下载」的直接上传也支持空工作区。已有素材继续按版本追加下载，不覆盖同名文件；已发布的端口自动同步。

尚未绑定端口时文件仍会保存，但没有可访问的 HTTP 下载地址。Agent 可在同一对话询问监听端口和公告地址；用户明确指定后通过发布和端口工具完成配置。回答卡片也能补充上传文件。发送后的附件记录随历史和中断后的继续任务保留；用户移除附件只改变本轮选择，不删除已经托管的文件。

### 对话文件拖拽（4.16.1）

可将一个或多个文件拖到 AI 助手输入框，或 Agent 提问卡片的回答框，松开后立即上传为附件，再发送托管要求。拖入时显示上传提示；文本拖动仍保持原有编辑行为。文件夹请先压缩为 ZIP，单轮 8 个、单文件 128 MiB 的限制与点击上传一致。上传中不能再次拖入，任务执行中也不会接收新附件。移动端继续使用「上传文件」。
